# Skills de Claude Code — Humand

Repo compartido con skills de [Claude Code](https://claude.com/claude-code) para el equipo.

## Cómo usar

1. Cloná este repo.
2. Abrí Claude Code (`claude`) parado dentro de esta carpeta.
3. Los skills en `.claude/skills/` quedan disponibles automáticamente — invocalos con `/nombre-del-skill` o simplemente pidiéndoselo a Claude en lenguaje natural.

## Skills disponibles

- **`adapt-figma-sizes`** — adapta una pieza gráfica seleccionada en Figma a distintos tamaños (redes sociales, link previews, stories), rearmando el layout en vez de solo escalarlo.
